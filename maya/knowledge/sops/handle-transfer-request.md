# SOP — Handle transfer request

## Goal

Collect a clean transfer request (person, event/city, or deferral) and route it through the standard form.

## Steps

1. **Clarify request type:** another person, another event/city, or future date.
2. **Share the form:** https://sr-event.typeform.com/to/ccysEJGM
3. **Ask for confirmation reply** after submission.
4. **Capture identifiers** if needed: full name, registration email, current event/city.
5. **Do not confirm completion** until a human has processed the form.
6. **Seat-sensitive cases** (VIP upgrade, capacity): tag as city lookup / escalate if event is imminent.
