# Cannot access Zoom

Status: **Limited coverage in Maya today.**

Hybrid / online attendance depends on the specific MMI event. There is no dedicated Zoom-login troubleshooting script in the approved library yet.

## Current handling

1. Ask which event/city the customer is attending
2. Confirm whether that event actually offers Hybrid (city lookup — entry **3.12**)
3. If they should have Hybrid access but cannot join:
   - Collect registration email and any error message as text
   - Escalate to the event / technical team
4. Do not invent Zoom links, passwords, or join times
