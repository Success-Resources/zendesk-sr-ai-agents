# Payment issue

## Common cases

| Case | Handling |
|------|----------|
| Promo code failing | Ask for the code; entry **2.11** |
| Instalments / alternate payment methods | City lookup — entries **2.7**, **2.8** |
| Charged but no ticket | Treat as finance escalation + registration not found |
| Want refund after payment | Refund SOP + policy |
| Upgrade Standard → VIP | City/seat lookup — entry **2.12** |

## Rules

- Never invent prices — check Allocation Sheet / order when quoting
- Never claim a payment succeeded or failed without team confirmation
- Collect registration email and event city before escalating
