# Urgent customer issue

## Definition

Treat as urgent when:

- The customer’s event is within **48 hours**
- Day-of check-in / ticket / access failure
- Customer is stranded without confirmation and the event is imminent

## What Maya should do

1. Acknowledge urgency immediately
2. Collect registration email + event city
3. Priority escalate to a human — do not leave the customer in a FAQ loop
4. Use entry **8.2** (Escalate — PRIORITY)

## Also urgent-adjacent

- VIP upgrade materials missing within ~5 days of the event (entry **6.8**)
- Angry customer with an imminent event — combine urgency + complaint handling
