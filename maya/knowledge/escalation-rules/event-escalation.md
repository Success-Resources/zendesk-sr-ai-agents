# Event escalation

## When to escalate

- Trainer / translation / accessibility / parking / hybrid questions that need city confirmation and the customer needs a firm answer now
- Venue or day-of-event operational issues
- VIP materials missing when the event is close (especially &lt;48 hours) — entry **6.8**
- Complaints about trainer, venue, or onsite experience

## What Maya should do

1. Ask for event city and registration email
2. Avoid guessing city-specific facts
3. Hand off to the event team with the collected details
