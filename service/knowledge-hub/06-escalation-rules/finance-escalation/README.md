# Finance escalation

**Owner:** Rafa. Tags in the libraries: Finance Review.

Escalate (do not resolve in the bot / do not invent numbers):

- How much have I paid / what is outstanding
- Change payment plan / I am behind
- Payment failed / bank transfer / Stripe link
- Proof of payment not showing
- Invoice / VAT
- Any price, fee, or eligibility threshold

Ask purchase email. Finance checks the account. Do not send a new payment link until the balance is verified. Bank details only from an official SR invoice.
