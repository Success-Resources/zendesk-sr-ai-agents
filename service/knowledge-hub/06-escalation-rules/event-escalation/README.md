# Event escalation

Hand to a human when the answer depends on a specific event and is not in the library:

- Trainer, translation, parking, venue, wheelchair access, lunch for a named city
- “Why am I not eligible to register yet?” after they already sent purchase email
- EWC / TTT registration conditions that need the order
- Company cancelled or postponed the event
- Question outside Maya / Quinn knowledge

Maya tag: City Lookup — ask which city first, then a human confirms if the library is not enough.
