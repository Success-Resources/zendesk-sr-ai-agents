# Cannot access Zoom

There is no dedicated “Zoom link” FAQ in the libraries yet. Use the **online access** answers (Quinn 5.1 and the access-link macro).

## Steps

1. Ask them to check inbox and spam for Success Resources mail.
2. Collect full name, purchase email, programme (MMI / QL / NWA / etc.).
3. Access is personal. Do not share logins. Do not paste a random magic link.
4. If the event is within 48 hours, escalate as urgent.

When a real Zoom SOP exists (which email the link comes from, when it is sent), add it here.
