# Registration not found

Usual causes: wrong email, not eligible yet (QL payment/sequence), already registered and reminder is automated, typo on the form.

## Steps

1. Ask full name, every email they might have used, programme, city/date.
2. Maya: offer to correct registration details if the booking allows it.
3. Quinn: “not eligible yet” is usually payment status or programme order — verify, do not guess.
4. If still not found after lookup: holding reply, human checks the Allocation Sheet / CRM. Do not create a new booking in the draft.
