# SOP — Handle transfer request

**Agents:** Maya (MMI ticket), Quinn (QL programme date/person), Rafa if money/fees are involved.

## Steps

1. Confirm it is a transfer (date or person), not a refund.
2. Ask name, purchase email, current event, preferred new event or new participant name and email.
3. Look up the order / Allocation Sheet. Do not invent a fee.
4. Draft: we will check; nothing is changed until we confirm in writing.
5. If a fee or ineligibility appears on the order, state only after verification. Otherwise escalate to Finance/Management.
