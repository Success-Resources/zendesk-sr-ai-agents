# Email examples

Use the approved email in each topic file. This folder compiles every Maya and Quinn email in one place, plus Rafa macros live in the SOP/policy folders.

Sign-off on new drafts: none. Zendesk appends the brand signature ("To your success, Customer Service Team, Success Resources UK Limited ...") to every agent reply, so Maya's text ends after the last sentence. Start every reply with "Hi <first name>," or "Hello,".

Older Quinn library emails still end with “All the best, Evelin”. Remove it when sending.
